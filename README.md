# Brew & Bloom — Responsive Coffee Landing Page

A polished, mobile-friendly demo coffee storefront built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

## Features
- Responsive desktop, tablet and mobile layouts
- Sticky navigation and collapsible mobile menu
- Product category filters
- Functional client-side shopping bag with quantities and totals
- Customer review carousel
- Newsletter form with demo confirmation
- Keyboard accessible buttons and reduced-motion support

## Important demo limitations
- Product names, prices, reviews, and brand are fictional placeholders.
- Checkout is a demo; no payments or orders are processed.
- Newsletter does not send or store email addresses.
- Photos and Google Fonts require an internet connection.
- Replace sample images, brand copy, and contact links before a real business launch.

## Deploy
Push the folder contents to a GitHub repository and enable GitHub Pages from the main branch root.
